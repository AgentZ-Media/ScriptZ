ScriptZ v0.7.8 - Jetzt auch für Windows.

## Was ist neu

- **Windows-Support.** ScriptZ läuft jetzt nativ auf Windows 10 und
  Windows 11 (x64). NSIS-Installer per Doppelklick, kein Admin nötig,
  Auto-Updates funktionieren plattform-übergreifend wie auf macOS.
- **Plattform-Detection auf der Landing.** write-scriptz.com erkennt
  jetzt automatisch dein Betriebssystem und zeigt den passenden
  Download-Button (.dmg für macOS, .exe für Windows). Unter jedem
  Download-Button ein dezenter Link zur GitHub-Releases-Seite, falls
  die Detection daneben liegt oder du für eine andere Plattform laden
  willst.
- **Install-Hinweis pro Plattform.** macOS bekommt weiterhin den
  `xattr`-Befehl gegen Gatekeeper, Windows bekommt die SmartScreen-
  Anleitung („Weitere Informationen" → „Trotzdem ausführen"). Beides
  ist normal für unsignierte Open-Source-Apps - Code-Signing-
  Zertifikate kosten Geld und solange das nicht eingespielt ist, sind
  die paar zusätzlichen Klicks der Preis dafür, dass ScriptZ kostenlos
  und ohne Konto bleibt.

## Unter der Haube

- Release-Pipeline auf vier Jobs umgebaut: erst macOS, dann Windows,
  beide bauen ins selbe GitHub-Release, das `latest.json`-Manifest
  wird automatisch um den Windows-Eintrag ergänzt. Vercel wird erst
  nach beiden Builds getriggert, damit die Landing die neuen Asset-
  URLs in einem Rutsch zieht.
- Tauri-Config bekommt einen `bundle.windows`-Block mit NSIS im
  `currentUser`-Mode (kein Admin-Prompt bei Auto-Updates) und
  Webview2-Bootstrapper als Fallback für ältere Windows-10-Versionen.

## Updating

Klick auf die grüne Update-Pille im File-Browser-Footer installiert
v0.7.8 in place. Auf Windows greift dafür der NSIS-Silent-Installer,
SmartScreen meldet sich beim Update nicht mehr.
